# Mobile MCP 앱 동선 분석 스킬

과제 2 제출물입니다. PC와 Android 휴대폰을 USB 디버깅으로 연결한 뒤 설치된 토스 앱을 직접 탐색하고, 관찰한 사용자 동선 원칙을 여러 분야의 모바일 앱·웹 설계에 재사용할 수 있는 Codex 스킬로 정리했습니다.

## 분석 대상

- 기기: Android 휴대폰
- 대상 앱: 토스 (`viva.republica.toss`)
- 탐색 범위: 홈, 혜택, 쇼핑, 증권, 전체 메뉴의 정보 구조와 화면 전환
- 제외 범위: 송금, 결제, 상품 가입, 개인정보 변경 등 금융 거래

## 저장소 구성

- `SKILL.md`: 스킬의 핵심 지침
- `references/domain-adaptation.md`: 다양한 산업에 적용하는 방법
- `agents/openai.yaml`: Codex 스킬 표시 및 호출 설정
- `ANALYSIS.md`: Mobile MCP 연결 및 앱 동선 분석 기록

## 사용 예시

```text
$toss-flow-design 배관 현장관리 모바일 웹의 전체 사용자 동선을 설계해줘
```

이 스킬은 토스의 브랜드, 문구, 아이콘, 화면을 복제하지 않습니다. 요약 중심 홈, 고정 탐색, 한 화면의 명확한 대표 행동, 점진적 정보 공개, 즉각적인 피드백 같은 일반적인 UX 원칙만 재사용합니다.
